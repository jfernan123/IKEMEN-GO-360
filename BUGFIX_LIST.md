# Bug-fix list

Bugs noticed while setting up RL training and investigating SmartAI (2026-10-24). None of these are fixed yet.
"Ikemen" means the reference source in `../Ikemen-GO/src`. Severity: **high** changes how fights play out, **medium**
affects some characters or tools, **low** is cosmetic or minor.
